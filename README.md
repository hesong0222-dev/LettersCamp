# Letters Camp Control

캠프의 일정, 사람, 자료, 물품, 참가자 정보를 세션 단위로 연결하고 준비부터 현장 실행까지 관리하는 운영진용 컨트롤 타워 MVP입니다.

## 핵심 화면

- 홈 대시보드: D-day, 준비율, 위험, 오늘 마감, 미배정 역할, 중요 변경
- 마스터 일정: 시간·장소·책임자·세션 준비 상태
- 업무 보드: 담당자·마감·상태, 새 업무 등록, 카카오 메시지→업무 후보
- 사람·역할: 가용시간과 역할 공백/중복 경고
- 자료·최종본: 버전과 승인 상태
- 물품·포장: 필요/보유 수량, 구매 필요, 적재 차량
- 참가자 운영: 교회·조·숙소·차량·납부
- 현장 모드: 지금/다음 일정, 준비 완료, 도움 요청, 비상 연락처

브라우저 상태는 `localStorage`에 자동 저장되며 JSON 백업을 내려받을 수 있습니다. 첫 버전은 서버 없는 정적 MVP라 다중 사용자 실시간 동기화·로그인·실제 카카오 알림은 아직 포함하지 않습니다.

기존 굿즈 재고 앱은 [`legacy-goods.html`](legacy-goods.html)에 원본 그대로 보존되어 있습니다.

## 배포

`main` 브랜치가 갱신되면 `.github/workflows/pages.yml`이 GitHub Pages에 자동 배포합니다.
